# Maskette — Kigurumi 头壳设计工具

Maskette 是一款根据角色立绘设计 Kigurumi 头壳的桌面应用。
提供参考图后，你可以和 AI 助手一起讨论，逐步做出设定图、成品头壳的正视图、四视图（正面、斜侧面、侧面、背面）、眼部特写，以及用文字写清形状和颜色的设计说明。
所有图片都能在内置编辑器里手动调整，每次结果都会保存在项目的版本历史中。

[English](README.md) · [日本語](README.ja.md)

## 运行环境

- Windows 10 / 11（64 位）
- 用于 AI 的以下任意一种（详见“接入 AI”）
  - AI 服务的 API Key（OpenRouter 等）
  - 已用 ChatGPT 或 Claude 付费订阅登录的 Codex CLI 或 Claude Code

暂无 macOS 版。

## 安装

1. 从发布页面下载 `Maskette_<版本>_x64-setup.exe` 并打开。
2. 如果出现“Windows 已保护你的电脑”，请点击“更多信息”→“仍要运行”。
   Maskette 目前还没有代码签名，所以会出现这个提示。
3. 按照向导安装。不需要管理员权限（只安装给当前用户）。
   如果电脑上没有 WebView2（微软用于显示界面的组件），安装程序会自动安装，此时需要联网。

有新版本时，Maskette 启动后会在项目列表上方提示。点击“更新”后，Maskette 会先关闭，安装新版本，完成后自动重新打开。也可以在设置的“应用更新”中检查，并可在此关闭启动时的检查。已有的项目和设置会保留。

如果无法在应用内更新，用同样的方式运行新的 `setup.exe`。提示“已安装”时，直接点“下一步”。接着会打开卸载界面：不要勾选“删除应用程序数据”，点击“卸载”，完成后点击“关闭”，就会回到安装界面继续安装。已有的项目会保留。

第一次启动时，项目列表里会有一个示例项目。不接入 AI 也能用它试试编辑器和导出。不需要的话可以删除，删除后不会再出现。

## 接入 AI

首次使用时，请打开界面右上角的齿轮图标（设置），选择要用的 AI 服务并填写 API Key。

- 最简单的方式是使用 [OpenRouter](https://openrouter.ai/) 的 API Key。保持默认设置，在“对话助手 LLM”的“OpenRouter 的 API Key”中填写并保存，参考图分析和生图也会使用同一个 Key。按用量向 OpenRouter 付费。
- API Key 保存在 Windows 凭据管理器中，不会写入文件。
- 也可以调用已用 ChatGPT 或 Claude 付费订阅登录的 CLI：Codex CLI 可用于对话、参考图分析和生图，Claude Code 可用于对话和参考图分析。只有 ChatGPT 付费订阅时，把设置里的“对话助手 LLM”“参考图分析 LLM”“生图后端”都选为“Codex CLI”即可，不需要 API Key。请留意各服务的使用条款，仅在自己的电脑上自己使用。

## 眼睛和立绘不一样时

生成的头壳正视图有时会把虹膜的颜色画得比立绘更鲜艳，或者把立绘里眯着眼笑的眼睛画成睁开的，和立绘不一样。这时可以用编辑器的“局部生成”只重画眼睛。

1. 在左侧“图片”中打开正视图的版本，再选择最左侧的“局部生成”。
2. 用画笔把双眼连同上下睫毛和眼尾一起涂成一整块区域，不要涂到眉毛和鼻子。与其分别小范围地涂两只眼睛，不如把双眼一起稍微涂大一些，效果更好。
3. 在“描述怎么改”中写明要改的地方和不要改的地方。
   - 让虹膜颜色和立绘一致的例子：“只把虹膜的颜色改成参考图立绘里的颜色（不要比立绘更鲜艳）。不要改变瞳孔的形状、眼睛的大小、位置、表情、睫毛和高光。”
   - 改成眯眼笑的例子：“按参考图立绘的样子，把眼睛改成上眼睑盖住虹膜上部、眯起来的笑眼。上眼睑画成弧形，下眼睑稍微向上抬起。不要改变瞳孔的形状、虹膜的颜色、眼睛的位置和睫毛的颜色。”
     只写“把眼睛眯起来”的话，上眼睑容易直直地垂下来，变成半睁的眼睛，所以要写明上眼睑的弧形和下眼睑的抬起。
4. 在“参考图（可选）”的“选择已有参考”中选择角色的原始立绘（正面），然后点击“提交给 AI 只重做这一块”。请不要选择只裁出眼睛的图片（会按立绘的画法直接贴上去）。

重画后的图片会作为新版本显示在右侧的助手栏中。虹膜的颜色一次可能改不到和立绘一样。这时可以再做一次局部生成，或者像“偏灰的绿色”这样把颜色写进说明里。眼睛里的反光也可能变小。

如果在“设置”里改了“生图后端”的“模型”，可能会出现别的差异，比如瞳孔变成竖长的椭圆，或者眼白下方多了灰色阴影。这时也按同样的步骤，写明要改的地方。

只想改一处时，与其在对话里请 AI 修改正视图，不如用编辑器的“局部生成”，涂抹范围以外不会改变。对话里的修改会重新生成整张图片，除了要求改的地方，背景颜色以及脸的位置和大小也可能略有变化。

## 眼部特写

头壳正视图里的眼睛很小，眼睛的设计可能不容易看清。

确认头壳正视图、生成四视图后，AI 助手会问你要不要再做一张眼部特写。答应后，它会把已确认正视图里的双眼和眉毛放大、画清楚（需要生成一张图片）。也可以直接在对话里说“做一张眼部特写”。

- 眼部特写是从已确认的正视图做出来的。想改眼睛时，请先修改正视图并重新确认，再重新做眼部特写。
- 小尺寸正视图里看不清的细节（高光形状、睫毛末端等）由 AI 补画。使用之前，请和正视图对照一下。

## 设计说明

AI 生成的图片，每张图里的眼睛和发型可能会略有不同。设计说明用文字补充图片不容易表达的形状和颜色。

做好眼部特写之后（或者你说不需要时），AI 助手会问你要不要写设计说明。答应后，用于参考图分析的 AI 会读取已确认的正视图、四视图和眼部特写，把眼睛、眉毛、嘴巴、肤色、头发、耳朵和饰品的形状与颜色写成文字（相当于一次分析）。也可以直接在对话里说“写一份设计说明”。

- 设计说明会以卡片形式显示在对话里。可以用“复制”粘贴到别处，或用“保存为文本”存成文件。
- 左右以看正视图时观看者的左右为准。图片之间有出入时以哪张为准，以及颜色在屏幕上和实物上会有差异，这些也会用固定的文字附上。
- 有写错的地方，或者想补充的内容（比如“希望两个星星发饰都能拆卸”），在对话里说明后会重新写。说“用日语”“用英语”，就会用那种语言写。
- 设计说明是 AI 看图写出来的。使用前请和图片对照一下。重新确认正视图后，也请重新写设计说明。

## 数据位置

- 项目和图片保存在 `%APPDATA%\app.maskette`。
- 在项目列表的菜单中选择“导出 .maskette”，可以把项目导出为一个文件，在另一台电脑上导入。Visual Studio Kigurumi 导出的 .vkp 文件也可以导入（.maskette 文件无法在 Visual Studio Kigurumi 中打开）。

## 卸载

在 Windows 的“设置”→“应用”中卸载 Maskette。
如果也要删除项目，请在卸载界面勾选“删除应用程序数据”。
如果也要删除已保存的 API Key，请在卸载前，在 Maskette 的“设置”中点击“全部恢复默认”（其他设置也会恢复为初始状态）。
