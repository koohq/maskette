# Maskette — 着ぐるみマスクのデザインツール

Maskette は、キャラクターのイラストから、着ぐるみマスクを工房に発注するための資料を作るデスクトップアプリです。
参考画像を追加すると、AI アシスタントと相談しながら、設定画、マスクの正面図、四面図（正面・斜め前・横・後ろ）を作成できます。
生成した画像は内蔵のエディターで調整し、新しいバージョンとして保存できます。

[English](README.md) · [简体中文](README.zh-CN.md)

## 動作環境

- Windows 10 / 11（64 ビット）
- AI を使うための、次のどちらか（詳しくは「AI の設定」）
  - AI サービスの API キー（OpenRouter など）
  - ChatGPT か Claude の有料プランでログインした Codex CLI・Claude Code

macOS 版はまだありません。

## インストール

1. 配布ページから `Maskette_<バージョン>_x64-setup.exe` をダウンロードして実行します。
2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます。
   Maskette はまだコード署名をしていないため、この警告が表示されます。
3. 画面の案内に従ってインストールします。管理者権限は不要です（今お使いの Windows ユーザーにだけインストールされます）。
   WebView2 ランタイム（画面の表示に使う Microsoft のコンポーネント）がない PC では、インストールの途中で自動的に追加されます。その場合はインターネット接続が必要です。

新しいバージョンに更新するときは、新しい `setup.exe` を同じ手順で実行します。作成したプロジェクトはそのまま残ります。

## AI の設定

最初に、画面右上の歯車のアイコン（設定）を開き、使う AI サービスを選んで API キーを入力します。

- いちばん簡単なのは [OpenRouter](https://openrouter.ai/) の API キーを使う方法です。初期設定のまま「チャットアシスタント」の「API キー」に入力して保存すると、参考画像の分析と画像生成にも同じキーが使われます。料金は、使った分だけ OpenRouter に支払います。
- API キーは Windows の資格情報マネージャーに保存され、ファイルには保存されません。
- ChatGPT や Claude の有料プランでログインした CLI も使えます。Claude Code はチャットと参考画像の分析に、Codex CLI は参考画像の分析と画像生成に使えます。各サービスの利用規約に配慮して、自分の PC で自分ひとりが使う場合に限ってください。

## 目が絵と違うとき

生成したマスクの正面図では、瞳孔が縦長になったり、白目の下に灰色の影が付いたりして、目が絵と違うことがあります。そのときは、エディターの「部分再生成」で目だけを描き直せます。

1. 左の「画像」で正面図のバージョンを開き、左端の「部分再生成」を選びます。
2. 両目を、上下のまつげと目尻の先まで含めて、ひと続きの範囲としてブラシで塗ります。眉と鼻は塗りません。片目ずつ小さく塗るより、両目をまとめて少し大きめに塗るほうが、きれいに仕上がります。
3. 「どう変えるかを書く」に、直したいところと変えたくないところを書きます。瞳孔の形は絵に合わせて書き換えてください。
   例：「目だけを参考画像の絵のとおりに描き直す。瞳孔は丸い輪の形にする（縦長の楕円にしない）。白目は下のふちまで明るく、灰色の影を付けない。目の大きさ・位置・表情と、虹彩の色・光は変えない。」
4. 「参考画像（任意）」の「追加済みの参考画像から選ぶ」で、キャラクターの元の絵（正面）を選び、「塗った範囲を再生成」を押します。目だけを切り抜いた画像は選ばないでください（絵の描き方のまま貼り付いたようになります）。

描き直した画像は、新しいバージョンとして右のアシスタント欄に表示されます。まつげの色が絵と少し違ったり、小さな光が足されたりすることがあります。気になるときは、もう一度部分再生成するか、色を言葉で書き足してください。

## データの保存場所

- プロジェクトと画像は `%APPDATA%\app.maskette` に保存されます。
- プロジェクト一覧で、各プロジェクトの「…」メニューから「エクスポート（.vkp）」を選ぶと、1 つのファイルに書き出せます。別の PC では「プロジェクトをインポート」で取り込めます。

## アンインストール

Windows の「設定」→「アプリ」から Maskette をアンインストールします。
プロジェクトも削除する場合は、アンインストールの確認画面で「アプリケーションデータを削除する」にチェックを入れます。
保存した API キーも削除する場合は、アンインストールする前に、Maskette の設定画面で「すべて既定に戻す」を押します（ほかの設定も初期状態に戻ります）。
