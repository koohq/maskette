# Maskette — 着ぐるみマスクのデザインツール

Maskette は、キャラクターのイラストから着ぐるみマスクのデザイン画を作るデスクトップアプリです。
参考画像を追加すると、設定画・マスクの正面図・四面図（正面・斜め前・横・後ろ）・目の拡大図と、形や色を文章で書いたデザインメモを AI アシスタントと相談しながら作成できます。
生成した画像は内蔵のエディターで調整し、新しいバージョンとして保存できます。

[English](README.md) · [简体中文](README.zh-CN.md)

## 動作環境

- Windows 10 / 11（64 ビット）
- AI を使うための次のどちらか（詳しくは「AI の設定」）
  - AI サービスの API キー（OpenRouter など）
  - ChatGPT か Claude の有料プランでログインした Codex CLI・Claude Code

macOS 版はまだありません。

## インストール

1. 配布ページから `Maskette_<バージョン>_x64-setup.exe` をダウンロードして実行します。
2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます。
   Maskette はまだコード署名をしていないため、この警告が表示されます。
3. 画面の案内に従ってインストールします。管理者権限は不要です（今お使いの Windows ユーザーにだけインストールされます）。
   WebView2 ランタイム（画面の表示に使う Microsoft のコンポーネント）がない PC では、インストールの途中で自動的に追加されます。その場合はインターネット接続が必要です。

新しいバージョンが出ると、起動したときにプロジェクト一覧の上でお知らせします。「更新する」を押すと、Maskette がいったん閉じて新しいバージョンをインストールし、終わると自動で開き直します。設定画面の「アプリの更新」からも確認でき、起動時の確認はここで止められます。作成したプロジェクトと設定はそのまま残ります。

アプリから更新できないときは、新しい `setup.exe` を同じ手順で実行します。「既にインストールされています」と表示されたら、そのまま「次へ」を押します。続いてアンインストールの画面が開くので、「アプリケーションデータを削除する」にチェックを入れずに「アンインストール」を押し、終わったら「閉じる」を押します。インストールの画面に戻るので、続けてインストールします。作成したプロジェクトはそのまま残ります。

初めて起動したときは、プロジェクト一覧にサンプルのプロジェクトが 1 つ入っています。AI の設定をしなくても、エディターで開いたりエクスポートしたりして試せます。不要なら削除できます。削除したサンプルが再び入ることはありません。

## AI の設定

最初に画面右上の歯車のアイコン（設定）を開き、使う AI サービスを選んで API キーを入力します。

- いちばん簡単なのは [OpenRouter](https://openrouter.ai/) の API キーを使う方法です。初期設定のまま「チャットアシスタント」の「OpenRouter の API キー」に入力して保存すると、参考画像の分析と画像生成にも同じキーが使われます。料金は使った分だけ OpenRouter に支払います。
- API キーは Windows の資格情報マネージャーに保存され、ファイルには保存されません。
- ChatGPT や Claude の有料プランでログインした CLI も使用できます。Codex CLI はチャット・参考画像の分析・画像生成の全てに、Claude Code はチャットと参考画像の分析に対応しています。ChatGPT の有料プランだけで使用する場合は、設定の「チャットアシスタント」「参考画像の分析」「画像生成」の全てで「Codex CLI」を選びます（API キーは不要です）。CLI は、各サービスの利用規約に従って、自分の PC で自分だけが使用してください。

## 目を元の絵に合わせるには

生成したマスクの正面図では、目が元の絵と異なることがあります。虹彩の色が絵より鮮やかになったり、目を細めた笑顔が開いた目になったりします。そのときはエディターの「部分再生成」で目だけを描き直せます。

1. 左の「画像」で正面図のバージョンを開き、左端の「部分再生成」を選びます。
2. 上下のまつげと目尻の先まで含めて、両目を一続きの範囲としてブラシで塗ります。眉と鼻は塗りません。片目ずつ小さく塗るより、両目をまとめて少し大きめに塗るほうがきれいに仕上がります。
3. 「どう変えるかを書く」に、直したいところと変えたくないところを書きます。
   - 虹彩の色を絵に合わせる例：「虹彩の色だけを参考画像の絵と同じ色にする（絵より鮮やかにしない）。瞳孔の形・目の大きさ・位置・表情・まつげ・光は変えない。」
   - 目を細めた笑顔にする例：「目を参考画像の絵のように、上まぶたが虹彩の上にかかる、細めた笑顔の目にする。上まぶたは弧を描き、下まぶたを少し持ち上げる。瞳孔の形・虹彩の色・目の位置・まつげの色は変えない。」
     「細めた目にする」だけだと上まぶたが水平に下がった半目になりやすいため、上まぶたの弧と、下まぶたを持ち上げることまで書いてください。
4. 「参考画像（任意）」の「追加済みの参考画像から選ぶ」で、キャラクターの元の絵（正面）を選び、「塗った範囲を再生成」を押します。目だけを切り抜いた画像は選ばないでください（イラストの目がそのまま貼り付けたように描かれ、マスクの顔から浮いて見えます）。

描き直した画像は新しいバージョンとして右のアシスタント欄に表示されます。虹彩の色は 1 回では絵どおりにならないことがあります。そのときはもう一度部分再生成するか、「灰色がかった緑」のように色を言葉で書き足してください。目の中の映り込みが小さくなることもあります。

設定の「画像生成」の「モデル」を変えた場合は、別の違いが出ることがあります。瞳孔が縦長になったり、白目の下に灰色の影が付いたりします。そのときも同じ手順で、直したいところを書いてください。

1 か所だけを直したいときは、チャットで正面図の修正を頼むよりエディターの部分再生成を使ってください。塗った範囲の外は変わりません。チャットの修正は画像全体を作り直すので、頼んだところのほかに背景の色や顔の位置・大きさが少し変わることがあります。

## 目の拡大図

マスクの正面図では目が小さいため、目のデザインが読み取りにくいことがあります。

マスク正面図を確定して四面図ができると、アシスタントが目の拡大図も作るかを尋ねます。頼むと、確定した正面図の両目と眉を大きくはっきり描き直した画像を作ります（画像 1 枚分の生成です）。チャットで「目の拡大図を作って」と頼むこともできます。

- 目の拡大図は、確定した正面図から作ります。目を直したいときは、先に正面図を直して確定し直してから、目の拡大図を作り直してください。
- 小さな正面図にない細部（光の形やまつげの先など）は AI が補って描きます。使う前に正面図と見比べてください。

## デザインメモ

AI が生成した画像は、画像ごとに目や髪形が少しずつ異なることがあります。デザインメモは、画像だけでは伝わりにくい形や色を文章で補うためのメモです。

目の拡大図を作ったあと（作らないと答えたときも）、アシスタントがデザインメモも書くかを尋ねます。頼むと、参考画像の分析に使う AI が確定済みの正面図・四面図・目の拡大図を読み、目・眉・口・肌・髪・耳・飾りの形と色を文章にまとめます（分析 1 回分です）。チャットで「デザインメモを書いて」と頼むこともできます。

- デザインメモはチャットにカードで表示されます。「コピー」でほかのアプリに貼り付けたり、「テキストで保存」でファイルにしたりできます。
- 左右は正面図を見たときの向き（向かって左・右）で書かれます。画像どうしが食い違うときにどれを優先するかと、色が画面と実物で変わることも、決まった文で添えられます。
- 違っているところや書き足したいこと（「星の髪飾りは取り外せるようにしたい」など）をチャットで伝えると、書き直します。「中国語で」「英語で」と頼むと、その言語で書きます。
- デザインメモは AI が絵を読んで書いたものです。使う前に絵と見比べてください。正面図を確定し直したときは、デザインメモも書き直してください。

## データの保存場所

- プロジェクトと画像は `%APPDATA%\app.maskette` に保存されます。
- プロジェクト一覧で各プロジェクトの「…」メニューから「エクスポート（.maskette）」を選ぶと、1 つのファイルに書き出せます。別の PC では「プロジェクトをインポート」で取り込めます。Visual Studio Kigurumi で書き出した .vkp ファイルも取り込めます（.maskette を Visual Studio Kigurumi で開くことはできません）。

## 送信するデータと送信先

Maskette は利用統計やクラッシュレポートを収集しません。外部とは次の場合にのみ通信します。

- **AI サービス（チャット・参考画像の分析・画像生成）**：設定で選んだサービスに、会話・参考画像・元にする生成済みの画像・Maskette から AI への指示を送信します。OpenRouter はこれらをモデルの提供元（Google や OpenAI など）に転送します。OpenRouter を選んだ場合は、設定画面でモデルと料金の一覧も取得します。Codex CLI は OpenAI に、Claude Code は Anthropic に送信します。送信したデータは各サービスの利用規約とプライバシーポリシーに基づいて取り扱われます。各 API キーは発行元のサービスにのみ送信します。
- **GitHub（更新の確認）**：起動時と「今すぐ確認」を押したときに、GitHub の最新の Release から更新情報（`latest.json`）を取得します。起動時の確認は設定の「アプリの更新」で止められます。「更新する」を押すと、同じ Release からインストーラーをダウンロードします。Web サイトを閲覧するときと同じく、GitHub には IP アドレスなどが送信されます。
- **Microsoft（インストール時）**：WebView2 ランタイムがない PC では、インストーラーが Microsoft から WebView2 をダウンロードします。

## アンインストール

Windows の「設定」→「アプリ」から Maskette をアンインストールします。
プロジェクトも削除する場合は、アンインストールの確認画面で「アプリケーションデータを削除する」にチェックを入れます。
保存した API キーも削除する場合は、アンインストールする前に Maskette の設定画面で「すべて既定に戻す」を押します（ほかの設定も初期状態に戻ります）。
