# Maskette — 着ぐるみマスクのデザインツール

Maskette は、キャラクターの絵から着ぐるみマスクのデザインを考えるデスクトップアプリです。
参考画像を渡すと、AI のアシスタントと相談しながら、設定画、仕上がりのマスクの正面図、四面図までを作れます。
どの画像も内蔵のエディタで手直しでき、結果はプロジェクトの履歴に残ります。

[English](README.md) · [简体中文](README.zh-CN.md)

## 動く環境

- Windows 10 / 11（64 ビット）
- AI のつなぎ先のどれか 1 つ（下の「AI をつなぐ」）

macOS 版はまだありません。

## 入れ方

1. 配布ページから `Maskette_<版>_x64-setup.exe` を取ってきて開きます。
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。
   Maskette はまだコード署名をしていないため、この警告が出ます。
3. 案内に沿って入れます。管理者の権限は要りません（自分のユーザーにだけ入ります）。
   WebView2（画面の表示に使う Microsoft の部品）が無い PC では、途中で自動で入れます。そのときはネットにつながっている必要があります。

新しい版が出たら、新しい `setup.exe` を同じように入れると上書きされます。作ったプロジェクトはそのまま残ります。

## AI をつなぐ

最初に、画面の上にある「設定」で AI のつなぎ先を選び、API キーを入れます。

- いちばん簡単なのは [OpenRouter](https://openrouter.ai/) の API キーを 1 本入れる方法です。会話・参考画像の分析・画像生成の 3 つとも、これで動きます。料金は使った分だけ OpenRouter に払います。
- API キーは、Windows の資格情報マネージャーに保存されます。ファイルには書かれません。
- ChatGPT や Claude のサブスクでログインした CLI（Codex CLI・Claude Code）を呼ぶこともできます。自分の PC で自分だけが使う前提にしてください。

## データの置き場所

- プロジェクトや画像は `%APPDATA%\app.maskette` に保存されます。
- プロジェクト一覧のメニューにある「.vkp をエクスポート」で 1 つのファイルに書き出し、別の PC で読み込めます。

## 消し方

Windows の「設定」→「アプリ」から Maskette をアンインストールします。
プロジェクトも消したいときは、アンインストールの画面でアプリのデータを消す項目に印を付けます。
API キーも消したいときは、アンインストールの前に Maskette の「設定」で既定に戻します。
